# Creative 2 Page Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A new `/creative-2` page that mirrors the homepage section by section, opens on a SaaS/Creative before/after slider hero, and shows the creative side in style A.

**Architecture:** Page-local components under `src/components/creative2/`; nothing the homepage imports is modified. The hero stacks two layers (SaaS below, creative on top, clipped with `clip-path: inset(0 0 0 var(--p))`); both layers tag their blocks with `data-block` and a small hook syncs each block's min-height to the taller of the two. All page copy lives in one file so Wael can approve it in one place.

**Tech Stack:** Vite, React 18, react-router-dom 7, Tailwind, Vitest (node env, `renderToString`), Playwright (already installed) for the box check against the dev server.

**Spec:** `docs/superpowers/specs/2026-11-15-creative-2-design.md` (reference mockup: `docs/superpowers/specs/2026-11-15-creative-2-mockup.html`, option A).

## Global Constraints

- Site copy in English, no em-dashes (`—`), no bold in copy, no invented figures or facts.
- Hero figures allowed as is: "134 posts", "3 languages", "5 brand projects".
- `/creative-2` is `noindex` and stays out of the sitemap and out of `prerenderRoutePaths`.
- No change to the homepage files (`src/pages/Index.tsx`, `src/components/HeroSection.tsx` and every section `Index.tsx` imports), to `/creative`'s rendering, or to the global nav.
- No new npm dependency. No GSAP. No scroll animations.
- Port 8080 is not touched. `npm run build` is never run. The dev server for checks is the one on port 8081 (`.claude/launch.json` entry `dev-8081`).
- Never stage `.claude/launch.json`, `public/responsive/*.webp`, `src/lib/responsive-image-manifest.ts` or the `ysg-mac-migration` bundle: always `git add` explicit paths.
- Commit steps run only if Wael approved committing at handoff, on branch `creative-2`; otherwise skip them and record that in the ledger.
- Style-A tokens come from the `.A` rules of the mockup: cream `#f4f3ee`, ink `#0e0e0e`/`#111`, lime badge `#c6f432`, title Inter 800, italic line Newsreader 500, black button, outline button, cards with a 4px left border, frame 1.5px `#111` with corner mark, halftone halo `radial-gradient(#111 1.1px, transparent 1.6px) 0 0/5px 5px` masked by the photo at scales 1.06/1.13/1.2, opacity .6/.3/.14.

## Review Focus

1. A phone user swiping vertically over the hero must scroll the page; only a horizontal drag moves the handle (Task 4 test on `touch-action: pan-y`).
2. Resizing the window after load (1280 to 375) must keep both layers aligned (Task 7 script resizes inside one page and re-checks).
3. A click on the visible SaaS strip must hit the SaaS layer's link, not the creative one (Task 7 `elementFromPoint` check).
4. Newsreader loading after first paint must not leave blocks misaligned (hook re-syncs on `document.fonts.ready`; Task 7 waits for fonts, then checks).
5. The homepage must stay byte-identical in source (Task 7 final step: `git diff --stat main -- <homepage files>` is empty).

```ts

import { clampPercent, percentFromPointer, nextPercentForKey, maxHeights, START_PERCENT } from "@/components/creative2/slider";

describe("creative2 slider", () => {
  it("starts at 50", () => expect(START_PERCENT).toBe(50));
  it("clamps to 0..100", () => {
    expect(clampPercent(-12)).toBe(0);
    expect(clampPercent(140)).toBe(100);
    expect(clampPercent(37.5)).toBe(37.5);
  });
  it("maps pointer x to percent of the container", () => {
    expect(percentFromPointer(300, { left: 100, width: 800 })).toBe(25);
    expect(percentFromPointer(50, { left: 100, width: 800 })).toBe(0);
    expect(percentFromPointer(1000, { left: 100, width: 800 })).toBe(100);
  });
  it("arrows move 5%, clamped; Home/End jump; other keys ignored", () => {
    expect(nextPercentForKey(50, "ArrowLeft")).toBe(45);
    expect(nextPercentForKey(50, "ArrowRight")).toBe(55);
    expect(nextPercentForKey(2, "ArrowLeft")).toBe(0);
    expect(nextPercentForKey(98, "ArrowRight")).toBe(100);
    expect(nextPercentForKey(40, "Home")).toBe(0);
    expect(nextPercentForKey(40, "End")).toBe(100);
    expect(nextPercentForKey(40, "a")).toBeNull();
  });
  it("keeps the taller height of each block", () => {
    expect(maxHeights({ title: 80, cards: 120 }, { title: 96, cards: 100, logos: 40 }))
      .toEqual({ title: 96, cards: 120, logos: 40 });
  });
});
```
